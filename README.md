###AgileFlow — All-in-One Project & Sprint Management System
AgileFlow is a modern, full-stack Project Management System engineered for software development teams. Moving beyond basic Kanban setups, it unifies the core strengths of Jira, Trello, GitHub Projects, and Notion into a single, cohesive developer workspace.

###🚀 Key Capabilities
Agile & Scrum Workflows: Sprint planning with Fibonacci story points, velocity calculation, interactive drag-and-drop Kanban boards, daily standup tracking, and retrospectives.

Notion-Style Wiki & Docs: Built-in rich project documentation with full version history and real-time activity timelines.

Analytics & Reporting: Dynamic dashboards featuring Burndown, Burnup, Velocity, and Team Workload charts powered by Recharts.

Enterprise Control: Role-Based Access Control (RBAC), real-time Socket.IO notifications, global full-text search, and automated AI story estimation.

###🛠️ Production Tech Stack
Frontend: React, javascript, Tailwind CSS, TanStack Query, Zustand, DnD Kit

Backend & DB: Node.js, Express, PostgreSQL, Prisma ORM, JWT + Refresh Tokens

Real-time & DevOps: Socket.IO, AWS S3/Cloudinary, Docker, GitHub Actions, Vercel & Render

Designed to showcase complex relational schemas, real-time sync, and scalable full-stack architecture—making it an ideal portfolio piece for modern software engineering roles.
